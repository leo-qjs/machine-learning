# 推荐学习顺序

## 第 1 节：神经网络为什么不是简单线性叠加

核心问题：

```text
为什么多层线性函数叠加还是线性？
为什么必须引入激活函数？
```

目标是理解：

[
f(x)=W_2(W_1x+b_1)+b_2
]

如果没有激活函数，本质仍然等价于：

[
Wx+b
]

所以神经网络真正的表达能力来自非线性激活。

---

## 第 2 节：单个神经元的数学结构

理解：

[
z=w^Tx+b
]

[
a=\sigma(z)
]

这里：

* (z)：线性打分
* (a)：激活输出
* (w,b)：参数

其实单个神经元就是你已经学过的逻辑回归结构。

---

## 第 3 节：多层网络的前向传播

理解：

[
x \rightarrow z^{[1]} \rightarrow a^{[1]} \rightarrow z^{[2]} \rightarrow a^{[2]} \rightarrow \hat y
]

目标是建立“数据在网络中如何流动”的直觉。

---

## 第 4 节：反向传播第一性原理

重点理解：

```text
损失函数变化
→ 输出层误差信号
→ 逐层往前传
→ 每层参数根据自己的责任更新
```

数学核心是链式法则：

[
\frac{\partial L}{\partial w}
=============================

\frac{\partial L}{\partial a}
\frac{\partial a}{\partial z}
\frac{\partial z}{\partial w}
]
